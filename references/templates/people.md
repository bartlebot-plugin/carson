# The household

Carson uses this list to work out who a document belongs to. The name in the first position of each line is the name Carson uses in file names.

## People

(One line per person, like this:)

- Pat — Pat Sample — runs Carson

## Pets

(One line per pet: name — kind — anything useful, such as the vet's name.)

## Homes

(One line per home: a short name — own or rent — the town.)

## Vehicles
